Racing Game — Programming 1 Final

A retro-style console racing game built in C# with Visual Studio.

About this project

This was the final project for Programming 1 at John Abbott College. The goal was to build a playable game entirely in a C# console application — no game engine, just code. The game runs in real time, tracks score, and ends when the timer hits zero or the player collides with a bomb.

Screenshots

How it works

The player navigates a vehicle through a field of bombs and fuel cans. Collecting fuel cans adds to the score. Hitting a bomb ends the run. A 60-second countdown adds pressure, and a gravity toggle changes how the player moves.
