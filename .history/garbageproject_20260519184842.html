Garbage Detection — Information Technology

A hardware + software system that detects garbage using a webcam and a Raspberry Pi Pico.

About this project

This project was built for the Information Technology course at John Abbott College. The goal was to combine hardware and software to create a real working detection system. A webcam detects garbage, and the signal is sent to a Raspberry Pi Pico on a breadboard which triggers LEDs as visual indicators.

Hardware setup

How it works

A webcam captures a live feed and detects the presence of garbage. When triggered, it sends a signal to the Raspberry Pi Pico. The Pico runs code written in Arduino IDE and controls two LEDs on the breadboard — one for a clean state, one for a detected garbage state.

Hardware

  • Raspberry Pi Pico
  • Breadboard
  • Blue + red + white LEDs
  • Resistors
  • USB connection
  • Webcam

Software

  • Arduino IDE
  • C++ (Arduino)
  • Code flashed to the Pico
